# Keyblast

Soundboard pour Windows : joue tes sons dans le chat vocal de tes jeux (CS2, Discord…) avec des touches globales.

- **Site, aide et achat de la version Pro :** https://www.keyblast.app
- **Télécharger la dernière version :** [Keyblast.exe](https://github.com/vincensinimat/keyblast-releases/releases/latest/download/Keyblast.exe)

Ce dépôt ne sert qu'à héberger l'installeur. Il ne contient pas le code de Keyblast.

## Composants tiers

Keyblast installe le pilote USB/IP open source [usbip-win2](https://github.com/vadimgrn/usbip-win2) (licence BSD 2-Clause), et son micro virtuel est adapté de [Virtual Cables](https://github.com/tarekwasfy01/Virtual-Cables) (licence BSD 2-Clause). Les textes de licence complets sont dans [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) et sont installés avec l'application.
